# BuildAid 1.2.3 Changelog

### 🎵 New Features (Music & Synchronized Channels)
- **Synchronized Music Rooms**: Connect with friends in rooms to listen to audio together in real time.
- **Automatic Server Channel Detection**: Joins the channel for your current Minecraft server automatically upon entering!
- **Custom Private Rooms**: Create and join private channels with room codes (supports cross-server listening).
- **YouTube & Web Audio Stream Support**: Add YouTube links, lives, and web radio streams directly to the shared queue.
- **In-Game Mini Player HUD**: Floating HUD element showing the current track title, artist, duration, room tag, and progress bar.
- **Official Cloud Relay Server**: Mod is pre-configured out-of-the-box with the official cloud relay (`wss://buildaid-sync-server.onrender.com`).

### 🛠️ Improvements & Fixes
- Silent auto-connection on world join (no chat errors when playing offline / solo).
- Optimized background MP3 decoder thread using pure Java JLayer.
- Cleaned up repository structure and updated documentation.

### 🎵 Novidades (Música e Canais Sincronizados)
- **Salas de Música Sincronizadas**: Conecte-se com amigos para escutar músicas juntos em tempo real.
- **Detecção Automática do Servidor**: Conecta automaticamente no canal do servidor de Minecraft em que você estiver jogando!
- **Salas Personalizadas**: Crie canais privados com códigos de sala (permite ouvir juntos mesmo em servidores diferentes).
- **Suporte a YouTube e Áudio Web**: Adicione links do YouTube, transmissões e web rádios diretamente na fila compartilhada.
- **Mini Player HUD na Tela**: Elemento flutuante elegante mostrando faixa atual, autor, sala e barra de progresso.
- **Servidor Oficial na Nuvem**: O mod já vem pré-configurado de fábrica com o servidor oficial (`wss://buildaid-sync-server.onrender.com`).

### 🛠️ Melhorias e Correções
- Conexão automática silenciosa ao entrar no mundo (sem mensagens de erro no chat ao jogar offline/solo).
- Decodificador de MP3 em thread secundária otimizada com JLayer puro Java.
- Estrutura do repositório limpa e documentação atualizada.
